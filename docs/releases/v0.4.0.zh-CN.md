# Meowcal Sub 2 v0.4.0

[English](https://github.com/PeterShanxin/Meowcal-Sub-2/blob/v0.4.0/docs/releases/v0.4.0.md)

**现在只要有一份字幕文件，妙影2 就能按电影的进度显示译文。** 手里有译文，它就找到对应的场景接着播。有原文，它就边看边译，准备好后自动跟播。

## ✨ 主要更新

- 🎯 **只有译文也能跟播。** 妙影2 会先翻译画面上的几句字幕，用它们在译文文件里找位置。确认几句都对得上后，字幕条就按文件里的时间往下播。下一句就算没从画面上认出来，也能照常显示。[#183](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/183)
- ▶️ **只有原文也可以先看。** 本地模型优先翻译你看到的对白，再利用空闲时间，参考上下文翻译其余字幕。整份译好后，字幕条会从你正在看的位置接着播。[#182](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/182)

## 修复与改进

- 没设置字幕来源，或搜不到片名时，点**翻译屏幕上的字幕**，再框选电影里的字幕，就能边看边译。[#185](https://github.com/PeterShanxin/Meowcal-Sub-2/issues/185)
- 第一份字幕还在加载时，如果改选另一份，工作室会保留你最后的选择。[#181](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/181)
- 悬浮字幕条重新连接后，会恢复当前这句字幕。如果这句已经播完，字幕条就留空。[#181](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/181)

## 📦 下载

| 你的 Windows 电脑 | 安装包 |
| --- | --- |
| Intel 或 AMD 处理器 | `meowcal-sub-2-v0.4.0-windows-x64-setup.exe` |
| 骁龙或其他 ARM 处理器 | `meowcal-sub-2-v0.4.0-windows-arm64-setup.exe` |

两种处理器都有便携版 ZIP。所有包都自带 Python 和 Meowcal Core v0.2.2。翻译模型可在设置中单独下载。可以用 `SHA256SUMS.txt` 校验下载文件。

从 v0.2.1 起，安装版支持应用内签名更新。v0.1.0 和 v0.2.0 需要手动运行新安装包。便携版需要重新下载并解压 ZIP。安装包没有 Authenticode 签名，Windows SmartScreen 可能提示发布者未知。
