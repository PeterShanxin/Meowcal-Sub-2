# Meowcal Sub 2 v0.3.0

[English](https://github.com/PeterShanxin/Meowcal-Sub-2/blob/v0.3.0/docs/releases/v0.3.0.md)

**Meowcal Sub 2 现在支持英语和简体中文界面，并换上了新的字幕卡片图标。**
这个版本还增加了一种屏幕字幕识别方式，让字幕选择和播放跟随更稳定。

## ✨ 主要更新

- 🌐 **用熟悉的语言操作工作室。** 在**设置 → 外观 → 界面语言**中选择跟随系统、English 或简体中文。工作室、托盘菜单、截图区域选择器和状态消息会随之切换；字幕语言独立设置。中文界面使用 **Meowcal Sub 2 · 妙影2** 名称（[#161](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/161)）。
- 🎯 **用 PP-OCRv6 识别字幕。** 新的文字识别引擎无需 Windows OCR 语言包，即可识别英语、中文、日语、西班牙语、法语和德语。自动模式在已安装所选语言包时继续使用 Windows OCR；你也可以在设置中选择 PP-OCRv6（[#152](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/152)）。
- 🖥️ **更稳地跟上对白。** 短暂的识别重读和恢复过程能保留字幕行的时间依据；确认跳转位置时，不会继续显示旧场景的字幕（[#153](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/153)）。

## 修复与改进

- 没有匹配的原文字幕文件时，可以选择**识别屏幕文字**；ASSRT 字幕包内的文件语言识别也更可靠（[#151](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/151)）。
- 更多来源返回电影匹配结果时，会保留你已选的字幕文件，包括未提供 IMDb ID 的匹配结果（[#154](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/154)）。
- 会话警告会显示在播放控制条中，观看时也能看到文字识别和翻译问题（[#156](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/156)）。
- 切换界面语言时保留尚未保存的设置。中英文用户指南已与当前控件保持一致（[#161](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/161)）。

v0.2.1 及之后的安装版支持已签名的应用内更新。v0.1.0 和 v0.2.0 需要手动运行安装包升级；
便携版需要手动更新。GitHub 安装包没有 Authenticode 签名，Windows SmartScreen 可能显示未知发布者警告。
