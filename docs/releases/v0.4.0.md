# Meowcal Sub 2 v0.4.0

[简体中文](https://github.com/PeterShanxin/Meowcal-Sub-2/blob/v0.4.0/docs/releases/v0.4.0.zh-CN.md)

**With just one subtitle file, Sub 2 can now show the translation on the film's timeline.** It can follow a translation you already have or build one from the original subtitles while you watch.

## ✨ Highlights

- 🎯 **Only have the translation?** Sub 2 translates a few on-screen captions to find your place in the file. Once different lines point to the same scene, the strip follows the file's timing. It can show the next line even if the screen reader misses it. [#183](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/183)
- ▶️ **Only have the original? Start watching.** The local model translates the current dialogue first and works on the remaining lines with context as you watch. When the full translation is ready, the strip picks it up at your current position. [#182](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/182)

## Fixes and improvements

- Start subtitles while your video is paused and the strip holds the current line until playback progresses. [#188](https://github.com/PeterShanxin/Meowcal-Sub-2/issues/188)
- With no subtitle service configured or no matching title, choose **Translate on-screen subtitles** and select the caption area to start watching. [#185](https://github.com/PeterShanxin/Meowcal-Sub-2/issues/185)
- Windows OCR can recover a Chinese caption when a busy background adds stray marks to one reading. [#186](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/186)
- If you choose another subtitle while the first is still loading, the studio keeps your latest choice. [#181](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/181)
- If the floating strip reconnects, it shows the current caption again, or stays blank if the dialogue has ended. [#181](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/181)

Installed copies from v0.2.1 onward support signed in-app updates. For v0.1.0 or v0.2.0, run the new installer manually. For a portable copy, download and extract the new ZIP. Windows SmartScreen may show an unknown-publisher warning because the installers have no Authenticode signature.
