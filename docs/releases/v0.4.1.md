# Meowcal Sub 2 v0.4.1

[简体中文](https://github.com/PeterShanxin/Meowcal-Sub-2/blob/v0.4.1/docs/releases/v0.4.1.zh-CN.md)

The app now checks for updates at most once a day when it opens. You can also check in **Settings → Updates**.

- **GitHub installer:** Existing installed copies can use the signed in-app update. For a fresh install, choose the x64 setup for Intel/AMD or the ARM64 setup for Snapdragon.
- **GitHub portable ZIP:** The app opens the release page when a newer ZIP matches your architecture. Download and extract it yourself; the app never replaces the portable copy or runs an installer.
- **Microsoft Store:** The Store edition opens the Store for updates, not GitHub. This GitHub release does not update the Store edition.
