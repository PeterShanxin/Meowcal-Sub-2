## Desktop screenshots

Upload the four PNGs in [screenshots](screenshots/) for the listing's language, ordered by the number in the file name. Use the captions in that language's listing. The images show a prepared session, search results, target-file selection and the subtitle editor.

The v0.4.0 screenshots use the Studio and its [demo server](../audit-20260926/ui/demo_server.py) with invented titles, subtitle files and a synthetic provider key. To refresh them, start the demo with its normal scenario from the corresponding release, open the Studio at 1440 × 960 and 2× scale, and search for **Paper Lanterns**. Select the first English WEB-DL source and the corresponding Chinese WEB-DL target. Finally open **Edit subtitles**. Capture each language separately using the same selections. Export the 2880 × 1920 screenshots as unaltered PNGs.
