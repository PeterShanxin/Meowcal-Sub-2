# Meowcal Sub 2 · 妙影2

## 简短描述

让喜欢的字幕译本跟上影片进度。妙影2 可以将字幕文件与画面上的对白对齐，也可以在你的电脑上直接翻译画面中的字幕。

## 描述

妙影2 读取播放器里看得见的字幕，把译文显示在悬浮字幕条上。先选画面上的语言，再选想看的语言。搜索电影或剧集、选好字幕文件，然后框住播放器里的字幕。

原文和译文文件都有时，妙影2 会从原文对白找到播放位置，按字幕作者设定的时间显示译文。只有译文文件时，它会先翻译画面上的几句对白，在文件里找到对应的场景后接着播。只有原文文件时，也可以直接开始看。本地模型优先翻译当前对白，同时准备其余字幕。整份译好后，字幕条会从你正在看的位置接着播。

没有字幕文件或字幕服务账号，也可以直接翻译画面中的字幕。文字识别和翻译都在你的电脑上运行。搜索字幕文件需要受支持的字幕服务凭据。本地翻译需要另行下载模型和运行环境。受保护的视频画面可能无法捕获。

## 功能

- 按片名、季或集搜索字幕文件。
- 只有译文文件时，也可以找到对应场景并跟播。
- 边看边译原文字幕，在后台准备其余译文。
- 没有字幕文件时，直接翻译画面中的字幕。
- 播放前检查、修改字幕文字和显示时间，并预览修正后的字幕。
