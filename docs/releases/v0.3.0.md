# Meowcal Sub 2 v0.3.0

[简体中文](https://github.com/PeterShanxin/Meowcal-Sub-2/blob/v0.3.0/docs/releases/v0.3.0.zh-CN.md)

**Meowcal Sub 2 now speaks English and Simplified Chinese, with a new subtitle-card icon.**
This release also gives you another way to read on-screen subtitles and keeps subtitle selection and playback steadier.

## ✨ Highlights

- 🌐 **Use the studio in your language.** Choose System, English or 简体中文 in **Settings → Appearance → Interface language**. The studio, tray, capture selector and status messages follow your choice; subtitle languages stay independent. The Chinese interface introduces **Meowcal Sub 2 · 妙影2** ([#161](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/161)).
- 🎯 **Read subtitles with PP-OCRv6.** The new OCR engine supports English, Chinese, Japanese, Spanish, French and German without Windows OCR language packs. Automatic mode keeps Windows OCR when the selected language is installed; you can choose PP-OCRv6 in Settings ([#152](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/152)).
- 🖥️ **Keep following the conversation.** Playback timing holds subtitle cues through brief OCR rereads and recovery, and avoids showing the old scene while confirming a seek ([#153](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/153)).

## Fixes and improvements

- Choose **Use on-screen OCR** when no source subtitle file matches, and find the right language more reliably inside ASSRT subtitle packages ([#151](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/151)).
- Movie results keep your selected subtitle files as more providers return matches, including matches without an IMDb ID ([#154](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/154)).
- Session warnings appear in the live dock, so OCR and translation problems remain visible while watching ([#156](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/156)).
- Switching interface language preserves unsaved settings. English and Chinese user guides cover the current controls ([#161](https://github.com/PeterShanxin/Meowcal-Sub-2/pull/161)).

Portable ZIPs are also provided. Python and Meowcal Core v0.2.2 are bundled;
models download separately. Verify downloads with `SHA256SUMS.txt`.

Installed v0.2.1 and later copies support signed in-app updates. Versions
v0.1.0 and v0.2.0 need a manual installer upgrade; portable copies update manually.
GitHub installers are not Authenticode-signed, so Windows SmartScreen may show
an unknown-publisher warning.
