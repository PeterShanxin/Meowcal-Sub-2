# 妙影2 隐私政策

[English](privacy.md)

本政策适用于个人开发者 Shanxin Li 提供的 Windows 应用 Meowcal Sub 2 · 妙影2。

## 观看视频

开始会话后，应用读取你框选区域内的字幕。为了判断画面是否还在播放，应用还可以采样字幕周围的播放器画面，并向 Windows 读取音频会话的活动状态和音量大小。应用不会录制麦克风声音或影片音轨。文字识别、对白匹配和翻译均在你的电脑上进行。应用不会向云端翻译服务发送画面、识别出的对白或译文。

## 字幕服务和下载

搜索字幕文件时，你启用的服务（OpenSubtitles、SubDL 或 ASSRT）会收到片名、语言选择、搜索或下载所用的标识，以及该服务要求的凭据。可选的 TMDb 查询会获取影片信息和海报。下载模型或运行组件时，应用会连接对应的下载服务。工作室可能会从 Google Fonts 加载字体。安装版可以联系相应的发布渠道检查应用更新。每个接收方都能收到正常连接所需的信息，包括你的 IP 地址。

你可以在设置中分别关闭字幕来源和 TMDb。直接翻译屏幕字幕使用本机已安装的翻译模型，无需字幕服务账号。

## 电脑上保存的文件

应用在你的 Windows 用户账户下保存设置、下载的字幕、编辑后的副本、缓存和日志。字幕服务凭据以明文形式保存在本地配置文件中。日志可能包含搜索词、片名、文件名和错误。以详细模式运行后台时，日志还可能记录识别出的对白和字幕。开启逐次捕获诊断后，识别数据会传给你电脑上的工作室。

停止会话或退出应用即可停止捕获。要清除已保存的凭据，请在设置中删除并保存。退出后可以移除本应用的本地文件。[用户指南](../user-guide.zh-CN.md)说明了存储和日志位置。删除本地数据不会删除已发送给字幕服务的信息。

## 支持和联系

请求帮助时，请自行选择愿意提供的信息。GitHub 问题是公开的。请勿在报告中附上私人观看画面、完整日志、密码或字幕服务密钥。有数据隐私问题时，请直接联系维护者 [shanxin@u.nus.edu](mailto:shanxin@u.nus.edu)。
