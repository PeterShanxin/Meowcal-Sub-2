# Meowcal Sub 2

## Short description

Watch a film with the subtitles you choose. Match a translated subtitle file to the picture, or translate the captions on your screen with a local model.

## Description

Meowcal Sub 2 follows subtitles in your video player and shows a translation in a floating strip. Choose the language you see on screen and the language you want to read. Search for the movie or episode, choose your subtitle files, and draw a box around the captions.

With both the original and translated files, the app finds your place in the original dialogue and displays the translation at the times set by its author. If you only find a translated file, the app translates several on-screen lines to locate the scene. If you only find the original file, you can start watching while the local model prepares the rest of the translation. Once it is ready, the strip follows it from your current position.

You can also translate directly from the screen when you have no subtitle files or provider account. Text recognition and translation run on your PC. Subtitle search requires credentials for a supported provider. Local translation requires a separate model and runtime download. Protected video may prevent screen capture.

## Features

- Search for subtitles by film, series, season or episode.
- Follow a translated subtitle file when the original file is unavailable.
- Translate an original subtitle file in the background while watching.
- Translate visible captions directly when neither file is available.
- Edit subtitle text and timing, and preview the corrected track before playback.
