# 妙影 2 v0.4.1

[English](https://github.com/PeterShanxin/Meowcal-Sub-2/blob/v0.4.1/docs/releases/v0.4.1.md)

应用启动时最多每天检查一次更新，也可以在 **设置 → 更新** 里手动检查。

- **GitHub 安装版：** 可以在应用内安装签名更新。首次安装时，Intel／AMD 选 x64，骁龙选 ARM64。
- **GitHub 便携版：** 有适合当前架构的新 ZIP 时，应用会打开 GitHub 发布页。请自行下载和解压；应用不会覆盖现有文件，也不会运行安装程序。
- **Microsoft Store：** 商店版通过商店更新，不走 GitHub。本次 GitHub 发布不会更新商店版。
